# cat-reloaded-task

Solutions to the Cat Reloaded training tasks. Each task is a self-contained Express project with its own `package.json`; run `npm install` inside the task folder first.

| Folder | What it is |
| --- | --- |
| `Task-1/` | Members dashboard (add, edit, delete, filter by sub-circle and level, search by name) in JavaScript with Express, MongoDB and Pug. The brief is in `task.txt` |
| `Task-2/` | The same dashboard rewritten in TypeScript, with ESLint and `tsconfig.json`. The brief is in `task.txt` |
| `Task-3/` | Task manager API in TypeScript with Express, route validation and an in-memory task model |
